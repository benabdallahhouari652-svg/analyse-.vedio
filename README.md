# 🇩 Live DZ Analyze
**استوديو جزائري احترافي لتحليل الفيديو الرياضي — التقطيع، الرسم التكتيكي، الكتابة، الإحصائيات والمونتاج — داخل المتصفح.**

> من إعداد المطوّر والمؤسس: **بن عبد الله الهواري**
> مربّي رياضي · مدرب حراس مرمى · محلل أداء

## التشغيل
```bash
cd livetack
python3 -m http.server 8000 --bind 0.0.0.0
# ثم افتح http://localhost:8000
```
(يعمل أيضاً بفتح index.html مباشرة في معظم المتصفحات.)

## الميزات
- **التقطيع (Tagging):** 24 فئة أحداث قابلة للتخصيص، اختصارات 1→9 وحروف، قبل/بعد قابل للضبط، إيقاف تلقائي، فلترة فريقين.
- **الرسم على الفيديو:** قلم حر، خط، سهم، دائرة، مستطيل، مضلع، بقعة ضوء، تمويه، علامات لاعبين وأسهم تكتيكية، تراجع/إعادة، أثر الإطار السابق، تلاشي تدريجي.
- **الكتابة على الفيديو:** نصوص عربية متحركة (ظهور/انزلاق/كتابة) تُدمج في التصدير.
- **السبورة التكتيكية:** تشكيلات جاهزة (4-4-2، 4-3-3...) وأرضية ملعب.
- **الإحصائيات:** مؤشرات، توزيع الفئات، مقارنة الفريقين، خريطة المناطق، أكثر اللاعبين ظهوراً.
- **المونتاج:** ترتيب مقاطع، عناوين، إعادة بطيئة، تلاشي، علامة مائية، وتصدير فيديو (WebM/MP4).
- **تصدير:** CSV (Excel)، LongoMatch XML، JSON (نسخة المشروع)، تقرير PDF، صورة PNG.
- **فيديو تعريفي مولَّد** يشرح طريقة عمل التطبيق + **فيديو مباراة تجريبي** للتدرّب.
- حفظ تلقائي للمشروع في المتصفح + استيراد/تصدير.
