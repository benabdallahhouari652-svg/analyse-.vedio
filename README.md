## ✨ المميزات

- **تقطيع 24 فئة أحداث** (هجمة، دفاع، خطأ، تسلل، ركنية، ركلة حرة، هدف، بطاقة...) مع اختصارات لوحة المفاتيح.
- **الرسم على الفيديو (Telestration)**: سهم، خط، دائرة، مستطيل، بقعة ضوء، تمويه/تعتيم، علامات لاعبين، كتابة متحركة.
- **السبورة التكتيكية**: تشكيلات جاهزة (4-4-2، 4-3-3، 3-5-2...) وسحب اللاعبين.
- **الإحصائيات**: عدّاد لكل فئة حسب الفريق/الشوط مع تصدير.
- **المونتاج والتصدير**: تجميع اللقطات وتصدير فيديو (WebM عبر MediaRecorder)، إلى جانب تصدير CSV / XML / PDF / PNG / JSON.
- **جولة تعريفية**: مولّد فيديو توضيحي داخلي + مباراة تجريبية.
- **استيراد/تصدير المشاريع** بصيغة JSON، مع حفظ تلقائي محلي.
- **الواجهة**: عربي RTL، فاتح/داكن، متوافقة مع الهاتف.
- **الهوية**: علم الجزائر 🇩🇿 + توقيع المطوّر بصورته في الشاشة الأولى، نافذة «حول»، الفيديو التوضيحي، PDF وكل التصديرات.

## ▶️ التشغيل محلياً

```bash
cd livetack
python3 -m http.server 8000 --bind 0.0.0.0
# ثم افتح: http://localhost:8000
```

## 🔨 إعادة بناء النسخة المدمجة (بعد أي تعديل على js/ أو styles.css)

```bash
python3 build.py
```

يُخرج `publish/index.html` جاهزاً للرفع + الحزمة المضغوطة.

## 🧪 الفحوص

```bash
bash test/run.sh          # كل الفحوص (128 فحصاً)
```

أو فرادى:

```bash
node test/smoke.js                     # 70 فحصاً ثابتاً: بنية، صياغة JS، سلامة النسخة المدمجة
node test/dom.js index.html            # 29 فحصاً تشغيلياً على النسخة متعددة الملفات
node test/dom.js publish/index.html    # 29 فحصاً تشغيلياً على النسخة المدمجة
```

> الفحص التشغيلي يشغّل التطبيق فعلياً في متصفح وهمي (jsdom) ويتحقق من: عدم ظهور أي نافذة منبثقة عند الإقلاع،
> ظهور الفئات الـ24، تسجيل الأحداث، منع التسجيل قبل تحميل فيديو، حذف الأحداث، والحفظ التلقائي.
> يتطلب `jsdom` مرة واحدة: `cd test && npm install jsdom`

## 📱 PWA — التطبيق على الهاتف

التطبيق يُثبَّت على الهاتف كتطبيق مستقل بأيقونة، ويعمل **بلا إنترنت** بالكامل.

**التثبيت:**
- **أندرويد (Chrome):** قائمة ⋮ → «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية»
- **آيفون (Safari):** زر المشاركة ⬆️ → «إضافة إلى الشاشة الرئيسية»
- **حاسوب (Chrome/Edge):** أيقونة ⊕ في شريط العنوان

**الملفات المطلوبة للـ PWA** (اختيارية — الملف `index.html` يعمل وحده كتطبيق كامل):

| الملف | الدور |
|---|---|
| `manifest.webmanifest` | اسم التطبيق وأيقوناته ووضع العرض |
| `sw.js` | service worker — التخزين المؤقت والعمل بلا إنترنت |
| `icon-192.png`, `icon-512.png` | أيقونة التطبيق |
| `icon-maskable-512.png` | أيقونة أندرويد (maskable) |
| `apple-touch-icon.png` | أيقونة iOS |
| `og-image.jpg` | صورة المشاركة على واتساب/فيسبوك |

> 💡 إن غاب `manifest.webmanifest`، يُنشئ التطبيق بياناً في الذاكرة تلقائياً.
> أما `sw.js` فلا يمكن تعويضه (المواصفة تمنع تسجيل service worker من blob/data) —
> وبدونه يعمل التطبيق عادياً لكن بلا عمل بلا إنترنت.

### أيقونات التطبيق
مولّدة من `assets/logo.svg` عبر `tools/make_assets.py` (Pillow). لإعادة توليدها:

```bash
python3 tools/make_assets.py      # الأيقونات + صورة المشاركة
python3 build.py                  # إعادة بناء الملف المدمج
```

## 📱 ملاحظات الهاتف واللوح

- الرسم باللمس مدعوم عبر Pointer Events، مع `touch-action:none` على طبقة الرسم وشريط التقدّم
  لمنع تمرير الصفحة أثناء الرسم.
- على الأجهزة اللمسية يزيد حجم مقابض الألوان وأزرار الأدوات تلقائياً (`@media (pointer:coarse)`).
- `viewport-fit=cover` لدعم شاشات iPhone ذات الحافة.

> ⚠️ **مهم**: النسخة المدمجة (ملف واحد) تعمل دائماً حتى لو تعطّلت الملفات الخارجية،
> لأنها تحتوي الكود والأنماط والصورة داخلها.
